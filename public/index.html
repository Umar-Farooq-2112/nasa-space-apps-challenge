Named after Charon, Pluto's largest moon. In 1978 James Christy found it by noticing a bump on Pluto's image that moved from photo to photo. This app does the same with NASA's SPHEREx telescope.

How we know a find is real. Each photo is aligned to the same north-up grid using its own sky coordinates (WCS). Every star is located in every photo, small pointing shifts are removed using the stars that stay still, and only objects that move in a straight line across most photos are kept. Each find gets a speed, a direction, an error bar and a confidence, and is compared with the Gaia catalog via SIMBAD. Tested on eight known nearby stars and brown dwarfs: all six fast movers found, no false movers on the two variable stars.
