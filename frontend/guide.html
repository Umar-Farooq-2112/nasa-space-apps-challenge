Where do I get images? (no code needed)

Mover Spotter needs many images of the same patch of sky taken on different dates, as FITS files. Each file must have sky coordinates and a date in its header. Nearly every telescope archive provides that. Below: the full manual route for the two sources this project is built around.

Step 0 — Find your target's coordinates

  1. Open a name resolver in your browser, for example SIMBAD or NED, and search for the object's name.
  2. Copy its RA and Dec in decimal degrees (ICRS / J2000). Example format: RA 123.4567, Dec -12.3456.
  3. Fast-moving stars: catalogue positions are for the year 2000. A star that moves several arcseconds per year will have drifted a lot by the 2010s-2020s. Mover Spotter crops a window of about 200 pixels (several arcminutes for WISE), which is wide enough for most targets, but for very fast stars (more than ~10 arcsec per year) shift the position by the proper motion shown on the same SIMBAD page.

Source A — WISE / NEOWISE, one image per ~6 months (2010 onward) tested

These are the "time-resolved coadds" behind the public WiseView tool. Hosted at NERSC; plain web directory, no login. About 18 epochs per sky position.

  1. Find the tile name. Open unwise.me/imgsearch, enter your RA/Dec, pick any version and get a cutout. The downloaded archive contains file names like unwise-1342m076-w2-img-m.fits. The bold part (4 digits, p or m, 3 digits) is the tile name (the example shown here is the tile containing the brown dwarf WISE 0855).
  2. Open the epoch folder. Go to portal.nersc.gov/project/cosmo/temp/ameisner/neo8/. Folders e000/, e001/, ... are the time epochs.
  3. For each epoch (e000, e001, ... up to about e020) open eNNN/<first 3 digits of tile>/<tile>/, e.g. e000/134/1342m076/, and download unwise-<tile>-w2-img-m.fits (about 17 MB). w2 is the 4.6 µm band (best for cold objects), w1 is 3.4 µm. Pick one band. Epoch folders that do not contain your tile just show "Not found": skip them.
  4. Upload all the downloaded files in Mover Spotter (see "Using the app" below). Create the dataset with the RA/Dec from step 0, because these files are huge (2048×2048 pixels) and the app crops them around that position. The observation dates come from the file headers automatically.

Tip: the file names stay identical across epochs, so your browser will add (1), (2) ... that is fine. The app orders frames by the date in each header, not by file name.

Source B — SPHEREx (NASA, 2025 onward) from IRSA docs, not tested

SPHEREx is the mission this challenge is about. Its images come from the NASA/IPAC Infrared Science Archive (IRSA). When this app was built, IRSA's search service was down (the Data Explorer showed “TAP service does not appear to exist or is not accessible”), so I could not test these steps. They follow IRSA's documentation. If the Data Explorer works for you, this is the best source.

  1. Open the SPHEREx Data Explorer and go to the Spectral Image Search tab.
  2. Enter your target's RA/Dec (or name) and a small radius (for example 0.05°), then press Search. You get a table with one row per image, with its observation date.
  3. Download cutouts (small crops) rather than the full images. IRSA documents a Cutout Tool for this: cutout tool documentation. A size of about 0.1° is enough. Each cutout is a multi-extension FITS file; Mover Spotter reads the IMAGE extension.
  4. Upload the files. The app reads each file's detector (D1–D6) and groups by it. Use one detector at a time when you view them: each detector sees a different wavelength, so mixing them looks like movement.

You need at least 5 images in one detector for Mover Spotter. SPHEREx revisits the sky about every 6 months, so a patch has few dates so far; more appear as the mission continues.

Other sources

Any FITS image with sky coordinates (WCS) and a date in the header works, for example survey images from other archives or asteroid-tracking telescopes. Upload several of the same field and Mover Spotter does the rest.

Using the app

  1. On the main page press New dataset, give it a name, and (for big files such as Source A) type the RA/Dec from step 0. Press Create.
  2. Drag all your FITS files into the dashed box (or click it to choose files). Each file is reported as OK or skipped with the reason.
  3. Choose the Band, a View and press Show.
